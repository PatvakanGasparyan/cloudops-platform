# CloudOps Platform

Production-style DevOps portfolio project built to demonstrate application delivery, containerization, CI/CD, infrastructure automation, observability, security, and AWS deployment.

## Current Status

The project is under active development.

Currently implemented:

- FastAPI backend
- `/health` endpoint
- Python virtual environment
- Pinned backend dependencies
- Git version control

## Planned Architecture

The platform will include:

- FastAPI
- React
- PostgreSQL
- Redis
- Docker
- Docker Compose
- Nginx
- GitHub Actions
- Terraform
- AWS EC2
- AWS IAM and OIDC
- AWS Systems Manager
- Prometheus
- Grafana
- Loki
- Promtail
- cAdvisor
- Node Exporter
